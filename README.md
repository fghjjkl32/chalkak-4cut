# 찰칵 네컷

p5.js로 만든 웹 네컷 사진 서비스 프로토타입입니다. 조별 프로젝트용입니다.

## 바로 써 보기

**https://fghjjkl32.github.io/chalkak-4cut/**

Chrome으로 열고 카메라 권한을 허용하면 됩니다.

## 기능

- 카메라 연속 촬영: 3초 카운트다운, 플래시, 셔터 소리, 고른 컷 다시 찍기
- 제스처 촬영: 브이 ✌를 1초 유지하면 촬영 시작, 손바닥 ✋으로 꾸미기로 이동
- 얼굴 필터: 강아지, 안경, 볼터치 (ml5.js faceMesh)
- 색 필터: 원본, 흑백, 세피아, 따뜻한 톤, 차가운 톤
- 커스텀 프레임: 1×4, 2×3, 2×4 레이아웃, 프레임 색, 무늬, 배경 이미지, 날짜와 문구
- 커스텀 스티커: 기본 스티커 8개, 짤 업로드와 자동 누끼, 옮기기·크기·회전·삭제
- 펜 낙서: 프레임 위에 펜으로 그리기, 색·굵기, 지우개, 되돌리기
- 저장: 사진(PNG), 움직이는 네컷(GIF), 동영상(WebM)

## 파일과 담당

| 담당 | 파일 | 내용 |
|---|---|---|
| 정창원 | `camera.js`, `sound.js`, `export.js`, `filters.js`, `face.js` | 카메라 촬영, 다시 찍기, PNG·GIF·WebM 저장, 색 필터, 얼굴 필터 |
| 전건우 | `frame.js`, `pen.js` | 프레임 꾸미기(레이아웃, 색, 무늬, 배경, 문구와 날짜), 펜 낙서 |
| 최진환 | `cutout.js`, `stickers.js` | 짤 자동 누끼, 커스텀 스티커 |
| 백은지 | `gesture.js` | 제스처로 원격 촬영 |
| 공통 | `sketch.js`, `ui.js` | 화면 흐름과 조작 패널 (자기 기능의 버튼은 각자 연결) |

`chalkak-4cut.html`은 위 파일을 한 파일로 합친 공유용 사본입니다.

## 로컬에서 실행

카메라는 `https`나 `localhost`에서 동작합니다.

```bash
python3 -m http.server 8777
# 브라우저에서 http://localhost:8777 열기
```

p5.js 1.11.11과 ml5.js 1.3.1을 CDN에서 불러오므로 인터넷 연결이 필요합니다. 사진과 영상은 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.
